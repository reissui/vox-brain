# Retired: Brain Note.app dictation

This legacy direct-capture app is retained only as historical source. Do not
install it or use `apps/brain-dictation/install.sh` in production.

Use the standalone [Brain.app](../brain-menu/README.md) with a separately
installed VoxType service. Brain owns the Fn gestures, VoxType transcribes
locally, and the result is pasted into the active application. Follow the
[authoritative client onboarding](../../remote/setup.md#8-install-and-onboard-the-standalone-client-on-the-personal-mac).
